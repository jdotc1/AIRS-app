# Ready-to-open examples

Import `mixed.audit.json` into the native app to explore the result vocabulary
without requiring a Python interpreter. The app itself still needs to be built
on a Mac. Open `mixed.audit.html` in a browser for a static report.

| File | Contents |
| --- | --- |
| `mixed.audit.json` | Nine synthetic functions with agreement, inconsistency and unresolved outcomes |
| `mixed.audit.html` | Escaped standalone HTML view of the same evidence |
| `before.audit.json` | Three supported synthetic functions |
| `after.audit.json` | Two deliberately changed metadata rules |
| `before-after.diff.json` | Three symbol candidates, two changed, one unchanged |
| `selected.macscope-handoff.json` | One supported inconsistency in the proposed adapter format |

These reports are generated by `scripts/generate-examples.py`. They preserve
the model, exact image identity and scope; they are not reports of third-party
defects. JSON imported into the app is validated for internal consistency, not
authenticated as proof that analysis was run by a trusted author.
